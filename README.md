# 🛒 E-Commerce REST API

A RESTful API built using Java and Spring Boot to manage products, categories, customers, shopping carts, and orders.

## 🛠️ Technologies Used

*  Java
*  Spring Boot
*  Spring Data JPA
*  Hibernate
*  MySQL
*  Maven
*  Swagger UI

## ✨ Features

*  Category Management
*  Product Management
*  Customer Management
*  Shopping Cart Management
*  Order Management
*  Automatic Stock Updates
*  Validation and Exception Handling

## 🔗 API Modules

| Module            | Endpoint          |
| ----------------- | ----------------- |
|  Categories     | `/api/categories` |
|  Products       | `/api/products`   |
|  Customers      | `/api/customers`  |
|  Shopping Carts | `/api/carts`      |
|  Orders         | `/api/orders`     |

## ⚙️ Setup

1. Clone the repository.
2. Import the project into Eclipse or Spring Tool Suite as a Maven project.
3. Create the MySQL database and configure `application.properties`.
4. Run `EcommerceApplication.java`.

## 📘 API Documentation

After starting the application, open:

`http://localhost:8080/swagger-ui/index.html`
